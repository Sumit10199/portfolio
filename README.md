# Portfolio

Production-grade React portfolio powered by React Router, Tailwind CSS, Zustand, and Framer Motion.

## Getting Started

```bash
npm install
npm run dev
```

## Project Structure

```
src/
  components/
  pages/
  features/
  hooks/
  services/
  store/
  assets/
  data/
```

## Content Updates

- Project data: `src/data/projects.ts`
- Profile basics: `src/data/profile.ts`
- Skills: `src/data/skills.ts`
- Experience: `src/data/experience.ts`

Add screenshots to the `screenshots` array in each project (with a `src` and `alt`) to surface visuals on the project detail page.

## Build

```bash
npm run build
```
